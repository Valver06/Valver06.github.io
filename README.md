# 🚕 Pavones Tours

Página web de **Pavones Tours**, servicio de transporte de personas y turismo en Pavones, Golfito, Costa Rica.

🌐 **Sitio en línea:** https://valver06.github.io

---

## 📖 Sobre el proyecto

Pavones Tours es un servicio de transporte verificado ante el **CTP y el MOPT**, con años de experiencia en la zona de Pavones, Golfito. Cuenta con 2 vehículos tipo microbús en excelente estado y conductores responsables y amables.

Esta página web presenta los servicios, las tarifas y las formas de contacto para que los clientes puedan solicitar una cotización o reservar su viaje fácilmente.

## ✨ Secciones de la página

- **Inicio:** portada con llamado a reservar.
- **Servicios:** traslados al aeropuerto, turismo y transporte empresarial.
- **Nosotros:** información sobre el servicio.
- **Tarifas:** ruta corta, aeropuerto y tarifa por hora de espera.
- **Contacto:** teléfono, correo, formulario de cotización y botón de WhatsApp.

## 🛠️ Tecnologías

- HTML5
- CSS3 (diseño responsivo con Grid y Flexbox)
- Publicado con GitHub Pages

